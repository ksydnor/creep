# Editing your portfolio

Everything on your site (projects, images, your bio, contact links) is edited in one place: `https://psantani.art/keystatic`. Bookmark it. The login is the username `pari` and the password you were given; if you lose it, ask me for a new one.

## The two things you can edit

- **Projects**: every project on the site, with its title, description, images, colour and order.
- **Site**: everything else, including your name, bio, school, email, Instagram link, photo, CV and the homepage hero image.

## Making a change

Open the thing you want to edit, change it, press **Save**. That's it: the live site updates straight away. Refresh to see it. Each project also has a **Preview** link in the editor that opens its page on the site.

## Adding a new project

1. In **Projects**, click **Add**.
2. Tick **Hide from the site** so you can work on it without it being live. Untick it when it's ready.
3. Fill in the title (the web address is made from it), **Order** (1 is first; the site follows this order everywhere), category (the work index groups projects by it), course, year, tools and an accent colour (a hex code like `#e42525`; pick one at htmlcolorcodes.com). Tick **Show on the homepage** if it belongs in the featured grid.
4. Optional extras: a **Video link** (paste a YouTube or Vimeo page address; it plays above the gallery), **Links** (a live site, an Instagram post, a shop) and a **PDF** to offer as a download. All three show up next to Year, Course and Tools.
5. Short description (for lists), project note (the main paragraph), an optional highlight block, and optional story sections (a title, some text and an image each).
6. Upload a cover image, an optional thumbnail for the scrolling rows, and gallery images with optional captions. Every image asks you to describe it in one line, for people using screen readers and for search engines.
7. Leave **Tone**, **Layout** and the two hero fields alone unless a picture sits oddly in the big header.
8. **Save.**

**Images:** JPG or PNG straight from your exports is fine; the site resizes them for visitors. Aim for at least 1600px on the long edge, and no more than about 2400px.

## Reordering projects

Change the **Order** number on each project. Lower numbers come first.

## Site

- **Your name, subtitle, header eyebrow, site description, portfolio statement**: the text on the homepage.
- **About text**: your bio. The first paragraph also appears at the bottom of the homepage; leave a blank line between paragraphs.
- **School / program, contact email, Instagram link, photo of you, CV (PDF)**: all optional. Anything left empty simply doesn't appear. Once an email is set, a Contact link appears in the header and footer.
- **Homepage hero image**: the large picture behind your name.
- **Section headings**: the small labels and titles above each part of the site ("Featured work", "Recent works", "Work Index" and so on). Leave a field empty to keep the current wording.

## If something looks wrong

- Refresh once; if it still looks old, give it a minute.
- Nothing you do in the editor can break the site's design or code. Every version is kept, so the previous one can always be restored; just message me.
